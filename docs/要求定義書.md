# 要求定義書：選手向けフィジカル・モチベーション管理アプリ

## 1. プロジェクトの目的・背景

* **目的**: 常に数字（体重やフィジカル測定値）を意識させることで、選手のモチベーションを向上させる。

* **背景**: 一橋大学ラグビー部のS&Cコーチとして、データ重視かつBig3を中心としたストレングス指導を行っているため。約30名の選手が日常的に自身の数値を把握し、成長を可視化できる仕組みが必要であるため。

## 2. ターゲットユーザー

* **選手（約30名の男子大学生）**: 全員が所持しているスマートフォンから日々の数値を入力・確認する。

* **S&Cコーチ（松岡様）およびスタッフ**: Windows PCやAndroidスマホからチーム全体の入力状況や数値を一元管理する。

## 3. アプリの基本構成（最小限・デモ版）

デモ用の最小限の構成（MVP）として機能を絞り込みます。ITの活用レベルが「Lv.1（苦手・ほぼ使わない）」の方でも直感的に操作できるシンプルな画面設計を前提とします。

### 3.1. 選手向け機能（スマホ画面）

* **ダッシュボード（ホーム画面）**: 現在の出席率、直近の体重グラフ、主要なフィジカル数値（Big3のMAX値など）の表示。

* **日次データ入力**: 本日の「出席/欠席」の選択、および「体重（kg）」の入力。

* **フィジカルデータ入力**: 定期的に測定するBig3（ベンチプレス、スクワット、デッドリフト）などの数値入力。

### 3.2. コーチ・管理者向け機能（PC/スマホ画面）

* **チームダッシュボード**: チーム全体の当日の出席状況と、体重の推移一覧表示。

* **フィジカルデータ管理**: 選手ごとのフィジカル測定結果の一覧表示（数字を意識させるためのシンプルなランキング表示を含む）。

## 4. 非機能要件（動作環境など）

* **対応デバイス**:

* 選手用：スマートフォン（iOS / Android）。

* コーチ用：Windows PC / Androidスマートフォン。

* **操作性**: 入力の手間を極力減らし、数タップで日次入力が完了するUIデザイン。

## 5. 将来的な拡張構想（デモ版以降の追加検討）

* 怪我予防を重視する指導スタイルに合わせた、痛みや疲労度などのコンディション入力機能。

* 監督やヘッドコーチなど、他のスタッフとのデータ共有・コメント機能。

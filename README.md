# NUMBERS — 選手向けフィジカル・モチベーション管理アプリ

数字（体重・出席率・Big3）を常に意識させ、選手のモチベーションを高めるためのアプリです。
選手はスマホから毎日の出欠と体重、定期測定の Big3 を入力し、コーチはチーム全体の状況とランキングを確認できます。

- 仕様：`docs/要求定義書.md`、`docs/要件定義書.md`、`docs/実装メモ.md`
- 本番公開の手順：**`DEPLOYMENT.md`**（初めての方はこちらから）

## 主な機能

**選手**
- ホーム：今日の記録状況（今日が練習日かオフかも表示）、出席率、体重の推移グラフ、Big3 自己ベストとチーム内順位
- 記録する：出席／欠席（欠席のときは欠席理由をプルダウンで選択）と体重（前回値から ±0.1kg で調整）、今週の筋トレ遂行度（0〜10をタップ）、測定（Big3＋項目設定で追加した項目。自己ベスト更新で通知）
- ランキング：Big3合計・種目別・体重比・追加したフィジカル項目

**コーチ**
- チーム（ダッシュボード）：上部に4つのメニュー（押すと詳細だけを表示。もう一度押す／「← 選手一覧（トップ）に戻る」／下部メニューの「チーム」でトップに戻る）
  - 出欠席率：当日の出欠（欠席は理由も表示）、月別の出席数・欠席数・未入力・出欠席率・欠席理由の内訳（日程調整で設定した練習日ベース）
  - 筋トレ遂行率：週ごとのチーム平均と推移、選手ごとの週次推移・達成率、評価基準
  - 体組成：体重の推移と、項目設定の体組成の項目の最新値
  - フィジカル：ランキング、自己ベスト一覧
  - トップ（4つのどれも選んでいないとき）だけ、下に「選手一覧」表（名前列を固定・カテゴリ色分け・学年/FW・BK/カテゴリー絞り込み・全データCSV・最下行に平均（絞り込み中は表示中の選手の平均）。カテゴリー（レギュラー・ベンチ・ベンチ外）はバッジをタップで切り替え、レギュラー平均とその他平均を比較表示。出席率は今月の練習日ベース）
- 項目設定：測定項目の追加・変更・削除・並び替え（選手一覧と選手の入力画面に、この順番で自動反映）、筋トレ評価基準の編集
- 日程調整：月間カレンダーの日付をタップして練習日を ON / OFF（自動保存・今月の設定練習日数を表示）
- 選手管理：メンバー追加（「＋ メンバーを追加」で入力欄を開く。選手は名前・学年（1〜5年）・ポジション（PR〜FBの10種類。FW/BKは自動判定））、学年・FW/BKでの絞り込み、並び替え（学年が上の人が上。左の ⋮⋮ をドラッグ＆ドロップで入れ替え可。スマホのタッチ操作にも対応）、編集、削除

**ログイン**
- 選手：名前を選ぶだけ（合言葉なし）
- コーチ：名前 ＋ 合言葉

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面 | Next.js（App Router）、TypeScript、Tailwind CSS |
| データベース・ログイン | Supabase（PostgreSQL、Supabase Auth、RLS） |
| 公開（ホスティング） | Vercel |

## フォルダ構成

```
app/
  page.tsx            トップページ（アプリ本体を表示）
  layout.tsx          ページ全体の共通設定
  globals.css         デザイン
  api/admin/route.ts  コーチ専用の操作（メンバー追加など）をサーバー側で実行
components/           画面の部品（ログイン、選手画面、コーチ画面、グラフ）
lib/                  データの読み書き・集計
supabase/schema.sql   データベースを作るSQL（Supabase で1回実行）
supabase/migrations/  あとから追加したSQL（既存のデータベースに追加で実行）
docs/                 仕様書・実装メモ
```

## 環境変数

Vercel の「Settings → Environment Variables」でのみ管理します（`.env.local` は使いません）。
設定する値は `DEPLOYMENT.md` の手順 4・5 を参照してください。

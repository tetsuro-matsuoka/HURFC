# NUMBERS — 選手向けフィジカル・モチベーション管理アプリ

数字（体重・出席率・Big3）を常に意識させ、選手のモチベーションを高めるためのアプリです。
選手はスマホから毎日の出欠と体重、定期測定の Big3 を入力し、コーチはチーム全体の状況とランキングを確認できます。

- 仕様：`docs/要求定義書.md`、`docs/要件定義書.md`、`docs/実装メモ.md`
- 本番公開の手順：**`DEPLOYMENT.md`**（初めての方はこちらから）

## 主な機能

**選手**
- ホーム：今日の記録状況、出席率、体重の推移グラフ、Big3 自己ベストとチーム内順位
- 記録する：出席／欠席と体重（前回値から ±0.1kg で調整）、Big3 の測定値（自己ベスト更新で通知）
- ランキング：Big3合計・種目別・体重比

**コーチ**
- チーム：日付ごとの出席・欠席・未入力の人数と一覧、全員の体重推移（7日差・30日差）
- フィジカル：ランキング、選手別の自己ベスト一覧（タップで詳細グラフ）
- 選手管理：メンバー追加、合言葉リセット、削除

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面 | Next.js（App Router）、TypeScript、Tailwind CSS |
| データベース・ログイン | Supabase（PostgreSQL、Supabase Auth、RLS） |
| 公開（ホスティング） | Vercel |

## フォルダ構成

```
app/
  page.tsx            トップページ（アプリ本体を表示）
  layout.tsx          ページ全体の共通設定
  globals.css         デザイン
  api/admin/route.ts  コーチ専用の操作（メンバー追加など）をサーバー側で実行
components/           画面の部品（ログイン、選手画面、コーチ画面、グラフ）
lib/                  データの読み書き・集計
supabase/schema.sql   データベースを作るSQL（Supabase で1回実行）
docs/                 仕様書・実装メモ
```

## 環境変数

Vercel の「Settings → Environment Variables」でのみ管理します（`.env.local` は使いません）。
設定する値は `DEPLOYMENT.md` の手順 4・5 を参照してください。

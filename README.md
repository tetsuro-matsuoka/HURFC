# NUMBERS — 選手向けフィジカル・モチベーション管理アプリ

数字（体重・出席率・Big3）を常に意識させ、選手のモチベーションを高めるためのアプリです。
選手はスマホから毎日の出欠と体重、定期測定の Big3 を入力し、コーチはチーム全体の状況とランキングを確認できます。

- 仕様：`docs/要求定義書.md`、`docs/要件定義書.md`、`docs/実装メモ.md`
- 本番公開の手順：**`DEPLOYMENT.md`**（初めての方はこちらから）

## 主な機能

**選手**
- ホーム：今日の記録状況（今日が練習日かオフかも表示）。コーチと同じ4つのメニュー（出欠席率・筋トレ遂行率・体組成・フィジカル）だけを表示し、押すと詳細（出欠はチーム平均と比較、体組成は体重と推移（区分平均の点線）、フィジカルはプルダウンで種目を選び最新値・自己ベスト・チーム内/区分内順位。Big3合計を選ぶと3種目と合計・体重比を並べて表示。その下に選んだ種目のチームランキング（1〜3位を大きく強調・自分の行に「あなた」））
- 下部メニューは「ホーム」「記録する」の2つ
- 記録する：ホームと同じ色の3つのボタン（毎日の記録＝緑/青・筋トレ遂行率＝黄土・フィジカル＝赤）。最初はボタンだけで、押すと入力フォームが開く（もう一度押すと閉じる）。毎日の記録は出欠カード（緑）と体重カード（青）に分けて入力し、体重は測ったタイミング（朝（起床後）・練習前・練習後・夜（就寝前））をボタンで記録できる。出席／欠席（欠席のときは欠席理由をプルダウンで選択）と体重（前回値から ±0.1kg で調整）、今週の筋トレ遂行度（0〜10をタップ）、測定（Big3＋項目設定で追加した項目。自己ベスト更新で通知）

**コーチ**
- チーム（ダッシュボード）：上部に4つのメニュー（押すと詳細だけを表示。もう一度押す／下部メニューの「チーム」でトップに戻る）
  - 出欠席率：当日の出欠（欠席は理由をバッジで表示。体重は出さない）、一番上にトータル出席率（今日までの練習日数×登録選手数が対象）と欠席理由統計（全期間）、月別の出欠席率にその月の欠席理由統計、月別の出席数・欠席数・未入力・出欠席率・欠席理由の内訳（日程調整で設定した練習日ベース）
  - 筋トレ遂行率：週ごとのチーム平均と推移、月別（‹ 月 › で切り替え）のチーム・FW・BK平均と選手別、選手ごとの週次推移・遂行率、評価基準
  - 体組成：上部に全体・FW・BK の体重の平均カード（日付を選べる・7日前比/30日前比）、その下に全体・FW・BK の体重の推移グラフ（期間を切り替え）、一番下に選手別の最新値
  - フィジカル：体組成と同じ構成。1枚目のカードで種目（プルダウン。体重比が ON なら「〇〇体重比」も）と「最新値 / 自己ベスト」を選ぶと、全体・FW・BK の平均カード（7日・30日前比）、推移グラフ（30日/90日/全期間）、選手別ランキング（体重比を併記）、自己ベスト一覧
  - トップ（4つのどれも選んでいないとき）だけ、下に「選手一覧」表（名前列を固定・カテゴリ色分け・学年/FW・BK/カテゴリー絞り込み・全データCSV・最下行に平均（絞り込み中は表示中の選手の平均）。カテゴリー（レギュラー・ベンチ・ベンチ外）はバッジをタップで切り替え、レギュラー平均とその他平均を比較表示。出席率は今月の練習日ベース）
- 項目設定：測定項目の追加・変更・削除・並び替え（選手一覧と選手の入力画面に、この順番で自動反映）、項目ごとに「体重比（相対値）も表示する」の ON/OFF、筋トレ遂行率の評価基準の編集（A〜B / A〜C / A〜D ごと）
- 日程調整：週ごとの筋トレメニュー（A〜B / A〜C / A〜D）をワンタップで設定。月間カレンダーの日付をタップして練習日を ON / OFF（自動保存・今月の設定練習日数を表示）
- 選手管理：メンバー追加（「＋ メンバーを追加」で入力欄を開く。選手は名前・学年（1〜5年）・ポジション（PR〜FBの10種類。FW/BKは自動判定））、学年・FW/BKでの絞り込み、並び替え（学年が上の人が上。左の ⋮⋮ をドラッグ＆ドロップで入れ替え可。スマホのタッチ操作にも対応）、編集、削除

**ログイン**
- 選手：名前を選ぶだけ（合言葉なし）
- コーチ：名前 ＋ 合言葉

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面 | Next.js（App Router）、TypeScript、Tailwind CSS |
| データベース・ログイン | Supabase（PostgreSQL、Supabase Auth、RLS） |
| 公開（ホスティング） | Vercel |

## フォルダ構成

```
app/
  page.tsx            トップページ（アプリ本体を表示）
  layout.tsx          ページ全体の共通設定
  globals.css         デザイン
  api/admin/route.ts  コーチ専用の操作（メンバー追加など）をサーバー側で実行
components/           画面の部品（ログイン、選手画面、コーチ画面、グラフ）
lib/                  データの読み書き・集計
supabase/schema.sql   データベースを作るSQL（Supabase で1回実行）
supabase/migrations/  あとから追加したSQL（既存のデータベースに追加で実行）
docs/                 仕様書・実装メモ
```

## 環境変数

Vercel の「Settings → Environment Variables」でのみ管理します（`.env.local` は使いません）。
設定する値は `DEPLOYMENT.md` の手順 4・5 を参照してください。
